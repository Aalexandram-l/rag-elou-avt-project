# Вторичная перегонка бензина (колонны К-6, К-7)

## 1. Назначение блока

Стабильный бензин НК–180 °C, полученный в блоке стабилизации (документ 05), состоит из широкого набора углеводородов. Для дальнейшего использования его разделяют на узкие фракции с разными пределами кипения. Такое разделение называется вторичной перегонкой. Оно проводится в двух последовательных колоннах: К-6 и К-7.

Узкие бензиновые фракции направляются на установки каталитической переработки бензина как сырьё. Их процессы в данный регламент не входят; они упоминаются только как потребители продуктов.

## 2. Сырьё

| Параметр | Значение |
| --- | --- |
| Сырьё | Стабильный бензин НК–180 °C |
| Расход, т/ч | 188 |
| Температура подачи, °C | 40 (после охлаждения), перед колонной нагревается до 100 °C |
| Источник | Куб колонны К-4 (документ 05) |

## 3. Схема блока

1. Стабильный бензин нагревается в теплообменниках до 100 °C и подаётся в колонну К-6.
2. В К-6 выделяется лёгкая фракция НК–85 °C (верх). Остаток (фракция 85–180 °C) уходит из куба.
3. Остаток К-6 подаётся в колонну К-7.
4. В К-7 остаток разделяется на среднюю фракцию 85–140 °C (верх) и тяжёлую фракцию 140–180 °C (куб).
5. Все три фракции охлаждаются и направляются потребителям.

## 4. Колонна К-6

Колонна тарельчатая, 60 тарелок. Выделяет фракцию НК–85 °C.

| Параметр | Значение |
| --- | --- |
| Давление верха, МПа | 0,35 |
| Температура верха, °C | 100 |
| Температура низа, °C | 175 |
| Кратность орошения | 3,0 |
| Греющая среда рибойлера | Тяжёлое дизельное топливо ДТ-2 (температура вывода 300 °C) |
| Продукт верха | Фракция НК–85 °C |
| Продукт низа | Фракция 85–180 °C |

Давление в К-6 поддерживается регулятором на линии отвода газов из рефлюксной ёмкости. Температура верха регулируется подачей орошения.

## 5. Колонна К-7

Колонна тарельчатая, 70 тарелок. Разделяет фракцию 85–180 °C на среднюю и тяжёлую.

| Параметр | Значение |
| --- | --- |
| Давление верха, МПа | 0,25 |
| Температура верха, °C | 135 |
| Температура низа, °C | 195 |
| Кратность орошения | 2,5 |
| Греющая среда рибойлера | Тяжёлое дизельное топливо ДТ-2 |
| Продукт верха | Фракция 85–140 °C |
| Продукт низа | Фракция 140–180 °C |

## 6. Продукты блока

| Фракция | Пределы кипения, °C | Назначение |
| --- | --- | --- |
| Лёгкая | НК–85 | Сырьё для установок изомеризации, компонент бензина |
| Средняя | 85–140 | Сырьё для установок каталитического риформинга |
| Тяжёлая | 140–180 | Компонент товарного бензина, сырьё для дальнейшей переработки |

Выходы фракций зависят от состава нефти; в учебном аналоге общий расход стабильного бензина — 18,8 % масс. на нефть (188 т/ч).

## 7. Влияние параметров

| Изменение | Результат |
| --- | --- |
| Повышение температуры верха К-6 | Фракция НК–85 °C утяжеляется, в неё попадают компоненты более тяжёлых фракций |
| Снижение кратности орошения К-6 | Ухудшается чёткость разделения |
| Повышение температуры низа К-7 | Увеличивается испарение тяжёлой фракции, она облегчается |
| Рост давления в колонне | Температуры кипения растут, требуется больше тепла |
| Недостаток тепла в рибойлере | Лёгкие компоненты остаются в кубе |

## 8. Контроль качества

| Фракция | Контролируемые показатели | Периодичность |
| --- | --- | --- |
| НК–85 °C | Конец кипения | Каждую смену |
| 85–140 °C | Начало и конец кипения | Каждую смену |
| 140–180 °C | Начало кипения, температура вспышки | Каждую смену |

Содержание воды и сероводорода в продуктах не допускается.

## 9. Особенности эксплуатации

- Колонны К-6 и К-7 работают с рибойлерами, греющая среда — горячее дизельное топливо. Это уменьшает расход пара и использует тепло процесса.
- Из рефлюксных ёмкостей периодически сливают воду.
- Предохранительные клапаны колонн сбрасывают в факельную систему (документ 12).
- При пуске колонны К-6 и К-7 включают после К-4, когда в системе есть стабильный бензин (документ 11).
