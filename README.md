# Семантический поиск по технологическому регламенту атмосферно-вакуумной перегонки нефти

**Курсовая работа (ТЗ №2).** 
Цель работы — создание прототипа RAG-системы, которая по вопросу на естественном языке находит релевантные фрагменты технологического регламента установки ЭЛОУ-АВТ и формирует связный ответ со ссылкой на источник.

Корпус представляет собой учебный аналог технологического регламента ЭЛОУ-АВТ. Он составлен по открытым источникам: научно-технической литературе, лекциям КНИТУ, учебным пособиям РГУ нефти и газа им. И.М. Губкина, ГОСТам и нормативным документам.

## Статус проекта (План на 10 недель)
- [x] **Этап 1:** Анализ предметной области, план корпуса, реестр источников.
- [x] **Этап 2:** Подготовка корпуса (14 документов в Markdown).
- [x] **Этап 3:** Чанкинг корпуса по структуре (получено 214 чанков).
- [ ] **Этап 4:** Построение векторного индекса и реализация поиска BM25.
- [ ] **Этап 5:** Гибридный поиск и переранжирование.
- [ ] **Этап 6:** Генерация ответов через LLM.
- [ ] **Этап 7:** Оценка качества (Recall@5, MRR).
- [ ] **Этап 8:** Разработка веб-интерфейса (Gradio/Streamlit).
- [ ] **Этап 9:** Написание пояснительной записки.
- [ ] **Этап 10:** Подготовка презентации и защита.
