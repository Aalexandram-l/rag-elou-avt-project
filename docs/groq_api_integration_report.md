## Отчёт о подключении и тестировании Groq API

В рамках работы над RAG-системой ЭЛОУ-АВТ была реализована интеграция с **Groq API** для генерации ответов на вопросы по технологическому регламенту.

Вместо локальной языковой модели для генерации ответов теперь можно использовать облачную модель через API. Для этого добавлена поддержка вызова Groq, настройки модели и передачи контекста, полученного в результате гибридного поиска.

Проведена ручная проверка работы API на контрольных вопросах. В частности, для вопроса о давлении в отбензинивающей колонне К-1 получен корректный ответ: **0,4 МПа**.

Также реализован отдельный скрипт `evaluate_groq.py` для автоматической оценки генерации через API. В качестве судьи используется локальная модель Qwen. По результатам тестирования на 25 вопросах получены следующие показатели:

- **Answer Accuracy:** 1,72 из 2,0 (86%).
- **Hallucination Rate:** 0%.
- Проверены также вопросы-ловушки, для которых система должна отказаться от ответа при отсутствии информации в регламенте.

Результаты оценки сохраняются в `results/metrics_generation_groq.md`.

Таким образом, интеграция Groq API позволяет использовать облачную генерацию ответов, снижая зависимость от вычислительных ресурсов локального устройства. При этом поиск релевантных фрагментов по-прежнему выполняется средствами разработанной RAG-системы.
