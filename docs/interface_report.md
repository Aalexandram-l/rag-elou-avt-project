# Веб-интерфейс (Streamlit)

## 1. Что сделано
Реализован пользовательский веб-интерфейс на базе фреймворка `Streamlit` для взаимодействия с RAG-системой. Интерфейс оформлен в корпоративном стиле (синий `#0093D0` и оранжевый `#F29400`).

В рамках этапа реализовано:
* Боковая панель с выбором метода поиска (hybrid, bm25, dense), метода генерации (extractive, llama) и опцией раскрытия аббревиатур.
* Фиксация количества фрагментов в контексте (`k=10`) в соответствии с требованиями ТЗ. 
* Блок ответа системы с отображением текста и раскрывающихся списков источников (документ + раздел).
* Кнопки с примерами запросов для быстрого тестирования.
* Кастомная тема оформления через `.streamlit/config.toml`.

## 2. Результаты тестирования
В ходе проверки были устранены следующие замечания:
* **Иконка в заголовке:** при использовании PNG-файла наблюдалась потеря качества при масштабировании. Решено заменой на векторный формат SVG.
* **Выравнивание элементов:** иконка и текст заголовка смещались относительно друг друга. Исправлено с помощью HTML-флексбоксов (`display: flex`).
* **Цвет интерактивных элементов:** цвет чекбокса не соответствовал дизайну. Исправлено настройкой `primaryColor` в конфигурационном файле темы.

## 3. Выводы
Интерфейс закрывает требования ТЗ по демонстрации работы системы. Использование `@st.cache_resource` обеспечивает быстрое повторное выполнение запросов без перезагрузки моделей. Строгий дизайн с минимальной палитрой цветов делает прототип готовым к презентации.

## 4. Код
* `streamlit_app.py` — основной файл приложения (стили, вёрстка, логика обработки запросов).
* `data/barrel.svg` — векторная иконка установки.
* `.streamlit/config.toml` — настройки цветовой темы.

## 5. Инструкция по запуску

**Шаг 1. Установка зависимостей:**
```bash
py -m pip install -r requirements.txt -i https://pypi.org/simple
```

**Шаг 2. Запуск приложения:**
```bash
py -m streamlit run streamlit_app.py
```
