# Гибридный поиск и переранжирование (Этап 5)

## 1. Что сделано
Реализован класс `HybridRetriever`, который объединяет два типа поиска: BM25 (лексический) и Dense (векторный). Для объединения используются методы Weighted Fusion и RRF (Reciprocal Rank Fusion). Дополнительно добавлено переранжирование (Re-ranking) с помощью кросс-энкодера `DiTy/cross-encoder-russian-msmarco`.

## 2. Результаты тестирования
Тестовый запрос: *«При какой температуре отбирается керосиновая фракция на атмосферной колонне?»*

**До переранжирования (только BM25 + Dense):**
Правильный ответ (`02_atm_block#007`) находился на 2–3 месте, так как общий раздел (`#002`) содержал больше совпадающих слов.

**После переранжирования (с кросс-энкодером):**
* При любом весе `alpha` (от 0.1 до 0.9) правильный ответ `02_atm_block#007` стабильно выходит на 1-е место (Score: 0.728).
* RRF также ставит его на 1-е место.

## 3. Выводы
**По подбору веса (alpha):** Перебор веса показал, что при наличии переранжирования вес не играет решающей роли — правильный ответ выходит наверх при любом `alpha`. Для базовой конфигурации выбран `alpha=0.5`.
**По переранжированию:** CrossEncoder позволяет отличить общие слова от конкретных фактов. Без него поиск отдавал первое место общему описанию (`#002`), а с ним — таблице с цифрами (`#007`).

## 4. Код
* `src/hybrid_retrieval.py` — класс `HybridRetriever` (Weighted, RRF, CrossEncoder).
* `tests/test_hybrid.py` — скрипт для тестирования.

## 5. Инструкция по запуску

Для проверки работы гибридного поиска выполните следующие шаги из корневой папки проекта:

**Шаг 1. Установка зависимостей:**
```bash
py -m pip install -r requirements.txt -i https://pypi.org/simple
```

**Шаг 2. Скачивание модели (выполняется один раз):**
Из-за возможных проблем с SSL-сертификатами при первом запуске `CrossEncoder` может не скачаться автоматически. Чтобы загрузить модель `DiTy/cross-encoder-russian-msmarco` вручную в кэш, выполните:
```bash
py -c "import os; os.environ['CURL_CA_BUNDLE']=''; from sentence_transformers import CrossEncoder; model = CrossEncoder('DiTy/cross-encoder-russian-msmarco'); print('Модель успешно загружена')"
```

**Шаг 3. Запуск тестового скрипта:**
```bash
py tests/test_hybrid.py
```
