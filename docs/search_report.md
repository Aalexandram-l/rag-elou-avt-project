# Реализация поиска (BM25 и Dense)

## 1. Что сделано
Реализованы два типа поиска по корпусу чанков:
1. **BM25 (лексический поиск):** класс `BM25Retriever` на базе библиотеки `rank_bm25` с кастомной токенизацией и стеммингом русского языка.
2. **Векторный (Dense) поиск:** класс `DenseRetriever`. Для генерации эмбеддингов используется русскоязычная модель `cointegrated/rubert-tiny2`, для хранения индекса — библиотека FAISS.

## 2. Результаты первого прогона
Тестовый запрос: *«При какой температуре отбирается керосиновая фракция на атмосферной колонне?»*

* **BM25** успешно находит правильный чанк `02_atm_block#007` (таблица с фракциями), ставя его на 2-е место.
* **Dense** также находит этот чанк, но на 3-м месте (модель `rubert-tiny2` немного путается в терминах без дополнительного обучения).

*Вывод:* BM25 лучше работает с точными терминами, Dense — с общими смыслами. Для улучшения качества на следующем этапе будет реализован гибридный поиск.

## 3. Структура кода
* `src/retrieval.py` — классы `BM25Retriever` и `DenseRetriever`.
* `tests/test_search.py` — скрипт для ручной проверки поиска.

## 4. Инструкция по запуску

Для установки зависимостей и запуска скрипта выполните следующие команды в терминале из корневой папки проекта:

1. Установка библиотек (включая `tf-keras` для корректной работы TensorFlow):
   ```bash
   py -m pip install -r requirements.txt -i https://pypi.org/simple
   ```
2. Запуск тестового поиска:
   ```bash
   py tests/test_search.py
   ```

**Важное примечание:** Для корректной работы Dense-поиска используется модель `cointegrated/rubert-tiny2`. В ходе работы она была предварительно загружена вручную из-за проблем с SSL-сертификатами при автоматическом скачивании. Модель сохранена в локальный кэш Hugging Face и используется при последующих запусках без повторной загрузки.
