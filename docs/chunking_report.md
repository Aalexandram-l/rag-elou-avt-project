# Этап 3. Чанкинг корпуса и метаданные

## 1. Что сделано на этапе
1. Реализован скрипт `src/chunking.py`, выполняющий структурный чанкинг с учётом заголовков Markdown (`#`, `##`, `###`).
2. Настроена логика обработки таблиц: каждая таблица вынесена в отдельный чанк с описанием колонок в метаданных.
3. Реализован модуль `src/text_utils.py` для токенизации, стемминга и раскрытия аббревиатур (словарь `data/glossary.json`).
4. Получен файл `data/chunks.jsonl` с результатами нарезки.

## 2. Параметры нарезки
* Ограничение по токенам (`MAX_TOKENS`): 800.
* Оценка размера страницы (`CHARS_PER_PAGE`): 2400 символов.
* Разделители: заголовки Markdown, пустые строки, конец таблицы.

## 3. Результаты
* Общее количество чанков: **214** (в том числе таблиц: 82).
* Количество разделов: 207.
* Все чанки содержат метаданные: `id`, `document`, `section`, `type`, `text`, `index_text`, `page`, `char_start`, `char_end`, `n_tokens`.

## 4. Пример чанка (JSON)
```json
{
  "id": "01_elou#001",
  "document": "01_elou.md",
  "section": "Блок ЭЛОУ. Обессоливание и обезвоживание нефти > 1. Назначение блока ЭЛОУ",
  "type": "text",
  "text": "Блок ЭЛОУ (электрообессоливающая установка) является первой технологической ступенью...",
  "index_text": "...",
  "page": 1,
  "char_start": 81,
  "char_end": 742,
  "n_tokens": 155
}
```

## 5. Инструкция по запуску (для воспроизведения)

Для запуска скрипта необходимо установить библиотеки и выполнить нарезку. В зависимости от настроек среды, команды могут отличаться.

### Классический способ (если pip настроен в PATH):
```bash
pip install -r requirements.txt
python src/chunking.py
```

### Рабочий способ (если pip не распознается или есть ошибки SSL-сертификатов):
```bash
py -m pip install -r requirements.txt -i https://pypi.org/simple
py src/chunking.py
```

**Ожидаемый вывод в консоли:**
`Чанков: 214 (таблиц: 82); разделов: 207 -> ...\data\chunks.jsonl`
