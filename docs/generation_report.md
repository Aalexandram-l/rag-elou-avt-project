# Генерация ответов через LLM 

## 1. Что сделано
На данном этапе реализован скрипт `src/generate.py`, который выполняет полный цикл RAG-системы (Retrieval-Augmented Generation):
1. **Поиск контекста:** с помощью гибридного поиска (BM25 + Dense + CrossEncoder) находятся топ-3 наиболее релевантных чанка.
2. **Промпт-инжиниринг:** формируется запрос к LLM, включающий:
   * Строгую системную инструкцию (запрет на галлюцинации, требование ссылаться на источники).
   * Найденные фрагменты регламента с указанием их номеров.
   * Текст вопроса пользователя.
3. **Генерация ответа:** локальная языковая модель (Qwen2.5-1.5B-Instruct) генерирует ответ на основе предоставленного контекста.
4. **Обработка ссылок:** скрипт выводит список источников (документ и раздел), которые были использованы для формирования ответа.

## 2. Используемые нейросети (архитектура)
Важно отметить, что в системе используется ансамбль из трех нейросетей, каждая из которых решает свою задачу:
1. **Bi-Encoder (`cointegrated/rubert-tiny2`)** — используется в `DenseRetriever` для векторного поиска. Она превращает текст в эмбеддинги, позволяя искать чанки по смыслу.
2. **Cross-Encoder (`DiTy/cross-encoder-russian-msmarco`)** — используется в `HybridRetriever` для переранжирования. Она оценивает смысловое соответствие пары «вопрос-чанк».
3. **Generative LLM (`Qwen2.5-1.5B-Instruct`)** — используется в `generate.py` для генерации текстового ответа. Запускается локально через движок `llama.cpp`.

## 3. Результаты тестирования

**Тест 1: Фактологический вопрос**
* **Вопрос:** *«При какой температуре отбирается керосиновая фракция?»*
* **Ответ системы:** `180–240 °C`
* **Источники:** `[1] 02_atm_block.md — Боковые погоны`, `[2] 06_material_balance.md`, `[3] 02_atm_block.md — СГК`.
* **Результат:** LLM корректно извлекла точный числовой факт из таблицы.

**Тест 2: Проверка на галлюцинации («ловушка»)**
* **Вопрос:** *«Какое октановое число у бензина после каталитического риформинга?»*
* **Ответ системы:** `Информация в регламенте не найдена.`
* **Результат:** Несмотря на наличие слова «риформинг» в найденных чанках, LLM поняла, что прямого ответа на вопрос там нет, и отказалась выдумывать факты.

**Тест 3: Вопрос с аббревиатурой**
* **Вопрос:** *«Чем занимается блок ЭЛОУ?»*
* **Ответ системы:** `Блок ЭЛОУ занимается обессоливанием и обезвоживанием нефти.`
* **Источники:** `[1] 01_elou.md — Назначение блока`.
* **Результат:** Благодаря словарю синонимов поисковик нашел нужный документ, а LLM дала четкий ответ.

## 4. Сравнение режимов: LLM (Qwen) vs Extractive

В скрипте реализовано два режима:
1. **Режим LLM (Qwen):** использует нейросеть для генерации связного ответа.
2. **Режим Extractive:** просто вырезает предложения с совпадением слов (без нейросети).

**Сравнение на тестовых вопросах:**
* **Вопрос:** *«При какой температуре отбирается керосиновая фракция?»*
  * *LLM (Qwen):* `180–240 °C` (четкий ответ).
  * *Extractive:* `С боковых тарелок выводятся керосиновая фракция 180–240 °C... Погон | Фракция, °C | Отпарная колонна [1]` (выдернуты предложения, есть мусор).
* **Вопрос (ловушка):** *«Какое октановое число у бензина после каталитического риформинга?»*
  * *LLM (Qwen):* `Информация в регламенте не найдена.` (правильный отказ).
  * *Extractive:* `Средняя | 85–140 | Сырьё для установок каталитического риформинга [1]` (ошибка, метод не понял, что в тексте нет ответа).

**Вывод:** Нейросеть Qwen (запускаемая через `llama.cpp`) справляется с пониманием смысла, отсеиванием «шума» и распознаванием вопросов-ловушек. Режим `extractive` подходит только для быстрой технической проверки пайплайна.

## 5. Инструкция по запуску

Для запуска системы необходимо выполнить следующие шаги в терминале (из корневой папки проекта):

**Шаг 1. Установка библиотек:**
```bash
py -m pip install -r requirements.txt 
```

**Шаг 2. Скачивание модели Qwen (около 1.1 ГБ):**
*(Выполняется один раз. Модель сохранится в папку `models/`, которая исключена из Git через `.gitignore`).*
```bash
py -c "import os; os.environ['CURL_CA_BUNDLE']=''; from huggingface_hub import hf_hub_download; hf_hub_download(repo_id='Qwen/Qwen2.5-1.5B-Instruct-GGUF', filename='qwen2.5-1.5b-instruct-q4_k_m.gguf', local_dir='./models')"
```

**Шаг 3. Запуск RAG-системы (генерация ответа):**
```bash
py src/generate.py "При какой температуре отбирается керосиновая фракция?"
```
